# Recipe catalog

Every card uses exactly one recipe. Choose the recipe from what the narration SAYS: look the sentence up in `playbook/narration-to-picture.md` first, then open the recipe's page here for its fields.

This file is generated by `python tools/catalog.py` from the code. Do not edit it by hand.

## Fields every card can have

| field | required | value | default | meaning |
|---|---|---|---|---|
| `at` | **yes** | words copied from this card's narration |  | first words of the narration where this scene starts (copy them exactly from work/reading.md) |
| `recipe` | **yes** | text |  | recipe id (recipes/CATALOG.md) |
| `says` | **yes** | text |  | what this part of the narration MEANS, in your own words (one sentence, 6+ words) |
| `variant` | no | text | `"auto"` | composition variant (A, B, C, D) or auto: the compiler rotates them so scenes never look the same |
| `date` | no | text |  | date badge top-left, e.g. "21 FEBRUARY 1916" — on every jump in time |
| `place` | no | text |  | place badge under the date, e.g. "VERDUN" |
| `name_card` | no | cast id |  | cast id whose name card shows (first appearance of a person); name/role come from cards/_film.json cast |
| `label` | no | object |  | {"text": "1-5 WORDS", "on": "phrase"} a short tag at the top centre |
| `counter` | no | object |  | {"to": 57470, "from": 0, "suffix": " KILLED", "prefix": "", "on": "phrase", "color": "#f08070"} a number counting up at the top (over the action) |
| `stamp` | no | object |  | {"text": "FAILED", "on": "phrase"} a rubber stamp slammed on screen |
| `time` | no | one of `day`, `dusk`, `dawn`, `night` |  | time of day of the place |
| `weather` | no | text |  | weather: rain · drizzle · downpour · snow · blizzard · haze · fog · dust · sandstorm · ash · leaves · petals · lightning, or {"kind": "rain", "amount": 0.9, "wind": 0.4} (amount 0..1, wind -1..1; lightning: "flash": [seconds]) |
| `tint` | no | one of `sepia`, `grey`, `cold`, `warm`, `night`, `red` |  | colour mood: grey = grief, sepia = myth/memory |
| `letterbox` | no | text |  | cinema bars for a dramatised moment (about one per chapter): true or a caption |
| `transition` | no | one of `cut`, `fade`, `dip`, `flash` |  | how this scene comes in (dip = big jump in time/place) |
| `ambience` | no | text |  | override the ambience bed (sea, wind, rain, room, office, battle, crowd, fire, engine, city_night) or "none" |
| `sfx` | no | list |  | extra sounds [{"on": "phrase", "id": "explosion"}] |
| `note` | no | text |  | free note for humans; ignored |
| `era` | no | one of `ww1`, `ww2`, `napoleonic`, `ancient`, `vietnam`, `modern` |  | rarely needed: this card is in another era than the film (a flashback) |
| `place_id` | no | text |  | a short name for a story place that comes back, e.g. "kaiser_study". Every card with the same place_id reuses the same setting and place/time tag; change only time/weather to show time passing |
| `tag` | no | text |  | place/time tag top-left, e.g. "Spa, Belgium · 29 September 1918". Set it on the first card of a place; cards with the same place_id inherit it; it stays put (no re-animation) while the tag does not change |
| `tag_on` | no | words copied from this card's narration |  | word(s) where the tag slides in (the date or the place name); default: at the start |
| `caption` | no | object |  | the film's BIG QUESTIONS only (opening, verdict): {"from": "first words", "to": "last words", "accent": ["Paris", "collapse"]} -> the words appear as they are spoken at the bottom, accent words in amber. Always on an acted scene |
| `stat` | no | object |  | rarely: one number that must be read, as engraved capitals over the scene: {"text": "About 56 km from Paris", "sub": "the closest since 1914", "top": "June 1918", "on": "fifty-six"} (at most one every ~2 minutes) |
| `paper_note` | no | object |  | rarely: the exact words of a quote/order typed on a paper note: {"lines": ["Fight on.", "Never surrender."], "kicker": "Orders, 1944", "on": "phrase", "accent_last": true} |
